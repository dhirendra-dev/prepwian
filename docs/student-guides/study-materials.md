# Study Materials: find, filter, and save resources

The Materials library brings study resources into one searchable place. This guide explains how to navigate it and build a simple study session from the resources available to your account.

## Open the library

Sign in to JEE Prep Hub and open **Materials** from the Study area or **Material Hub** from the feature menu. You can also open the [Materials page](https://jeeprephub.co.in/materials) directly. Materials access may show an on-screen unlock prompt; follow the prompt and use only access provided to you by the platform. Do not share account details or access credentials.

## Find a resource

1. **Choose a subject.** Use **All**, **Physics**, **Chemistry**, **Mathematics**, or **General** to focus the library.
2. **Search a title, topic, or description.** Enter a keyword in the search box—for example, a chapter name such as `kinematics`, `organic chemistry`, or `calculus`. Search updates as you type. Clear the search with the **×** button.
3. **Narrow the results.** Open the filter panel beside search to choose a class level and resource type. Available class choices include Class 11, Class 12, Dropper, and Both. Resource types depend on the materials in the library.
4. **Use Quick Access.** Shortcuts take you to common resource categories:

   | Shortcut    | Use it for                                    |
   | :---------- | :-------------------------------------------- |
   | Class Notes | Chapter notes                                 |
   | DPPs        | Daily practice problems                       |
   | PYQs        | Previous-year questions                       |
   | Books       | Reference material                            |
   | Revision    | Quick-revision resources                      |
   | Saved       | Materials you have bookmarked in this browser |

5. **Load more when needed.** Results are paginated. Select **Load more** to fetch the next set when the button appears.

You can combine a subject, class, resource type, and keyword to narrow the list. If you see **No materials found**, clear one or more filters, try a shorter search term, or return to **All** subjects.

## Choose and open materials

Each result shows available details such as its title, subject, resource type, class level, and topic. Check these labels before opening a resource so you pick material that matches the chapter and class you are studying.

- **Grid view** shows resource cards with **Open** and **Preview** actions.
- **List view** is a compact way to scan results and open a resource.
- **Open** takes you to the resource link in a new tab.
- **Preview** opens a preview when the linked source supports it; otherwise, use **Open**.
- Use the **bookmark** button to add or remove a resource from **Saved**.

> **Saved items are stored in this browser's local storage.** They are not a cloud-synced collection, so they may not appear on another device or browser. Clearing this browser's site data can remove saved bookmarks.

Some resources are hosted by external providers. Their availability, sign-in prompts, and download behavior may depend on that provider. If a link appears broken, note the resource title and what happened, then report it through JEE Prep Hub's official feedback channel.

## A simple study flow

- **Learn:** choose your subject and class, search for the current chapter, then review an appropriate set of notes or reference material.
- **Practice:** use the DPP or PYQ shortcut, then narrow by subject, class, or chapter keyword.
- **Review:** use the Revision shortcut for available revision resources and bookmark materials you want to revisit on this browser.

These are starting points, not a prescribed timetable. Choose resources that match your current syllabus, class, and preparation goals.

## Troubleshooting

| What you see                            | What to try                                                                                                                                    |
| :-------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------- |
| No results                              | Clear the search, select **All** subjects, or remove a class/resource-type filter.                                                             |
| A resource will not open                | Try **Open** instead of **Preview**; check whether the external provider requests its own access.                                              |
| A bookmark is missing on another device | Bookmarks are saved locally in the browser and do not sync between devices.                                                                    |
| The Materials page asks for access      | Follow the on-screen prompt. If you believe you should have access, contact a JEE Prep Hub administrator through the official support channel. |
