# Security Policy

JEE Prep Hub is under active development. Security fixes are applied to the current `main` branch. The latest tagged release is supported on a best-effort basis; older release snapshots are not guaranteed to receive backported fixes.

| Version               | Security support                          |
| --------------------- | ----------------------------------------- |
| `main`                | Supported; ongoing development            |
| Latest GitHub release | Best effort; update to the latest release |
| Older tags            | Not supported; no fixes guaranteed        |

## Reporting a vulnerability

Please do **not** open a public issue, pull request, or discussion with vulnerability details. If GitHub offers the private vulnerability reporting option for this repository, use the [private security advisory form](https://github.com/dhirendra-dev/prepwian/security/advisories/new). If that option is unavailable, contact the maintainer through the [GitHub profile](https://github.com/dhirendra-dev) and request a private channel.

A report is most useful when it includes the affected version or commit, the security impact, concise reproduction steps, and any safe mitigation you know. Do not include real student data, passwords, access tokens, service-role keys, or other secrets in a report.

The maintainer will acknowledge and review reports as soon as practical. Response and remediation times are not guaranteed. If a report is accepted, the maintainer will work on a fix and coordinate any necessary disclosure; if it is declined, an explanation will be provided where practical.

## Scope and safe testing

Only test systems and accounts you own or are explicitly authorized to assess. Do not access, alter, or retain another person's data, and do not perform denial-of-service, phishing, or other disruptive testing. Follow the [Code of Conduct](CODE_OF_CONDUCT.md) when communicating with the project.
