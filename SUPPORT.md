# Support

Choose the channel that matches your question so it reaches the right people.

## Using the study platform

For account, access, or study-platform questions, use the [JEE Prep Hub contact page](https://jeeprephub.co.in/contact). The form requires sign-in. Do not include passwords, authentication codes, or sensitive student information in a message.

## Reporting a software issue

Before opening a report, check the existing [issues](https://github.com/dhirendra-dev/prepwian/issues) and the [project roadmap](roadmap.md). Use the repository’s bug-report or feature-request issue form and include enough detail to reproduce the problem. Remove personal information from screenshots and logs.

## Documentation and contributions

For documentation problems, use the [documentation issue form](.github/ISSUE_TEMPLATE/documentation.yml). To propose or contribute a code change, read the [contribution guide](CONTRIBUTING.md) and [Code of Conduct](CODE_OF_CONDUCT.md).

## Security concerns

Do not report a vulnerability in a public issue. Follow the private reporting instructions in [`SECURITY.md`](SECURITY.md).

The project is under active development; response times and feature availability are not guaranteed.
