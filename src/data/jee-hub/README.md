# JEEHub paper data

The JSON question sets in this directory were copied from [`dhruv-programmes/JeeHub`](https://github.com/dhruv-programmes/JeeHub), upstream commit `63e2575d4a9484fca89d1a26b4bddd35761becf3`, under the MIT license. The upstream license notice is preserved in [`LICENSE`](./LICENSE).

Imported datasets include ten JEE Main 2024 shifts, selected JEE Advanced 2023 questions, BITSAT 2022, NEET 2022 (7 May), COMEDK 2023, and MHT-CET 2023. The exact filenames and question counts are recorded in [`manifest.json`](./manifest.json).

These are copied as the source repository provides them. Each dataset is presented as a **source subset** with its actual question count; none is represented as a complete official paper or a guaranteed official score. The JEE Advanced dataset contains 35 questions. Question diagrams and option images are retained as URLs to the upstream data's external `examgoal.net` image host; the image files themselves were not copied into this repository.
